# Progressive hints

Open only the level you need. This local trial has no automatic scoring/deductions. If hints later affect points, serve them through a facilitator or portal: files in a cloned repository are already readable and cannot enforce hint accounting.

## Level 1 — Observation
Separate configuration validation, source selection and component assembly. A later error may become visible only after fixing the earlier one.

## Level 2 — Direction
Compare the recursive strategy's overlapping region with its maximum chunk size. Compare the selected loader name with declared source keys. Identify which stage actually writes vectors.

## Level 3 — Location
Inspect `chunking.strategies.text` and `ingestion.sources` in the YAML. Inspect the `build_toolkit()` builder chain in `example_ingest.py`. Use the source-selection, parser/chunker and indexing sections of the SDK guide.

For a guided fix, ask the facilitator. Full reference files are kept outside this repository. The educational completion debrief exists in runtime code and is not a secret/security boundary; completion still requires real validation.
